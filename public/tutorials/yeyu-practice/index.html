关于题目与记录

选自《夜雨第二代竞赛课讲义.pdf》。题图中的年份、届次按讲义原标注保留，未另作真题版本校勘。知识点名称仅对公式缺失的目录标题作文字化整理。

总题量按独立题目计；同一道题用于比较不同方法时，解析随当前小节切换，完成状态和错因笔记仍按题同步。纯分类标题由下属知识点覆盖，不另凑题。部分正文方法在目录之外补入。

每题点击“看答案”可展开整理参考解答与必要步骤，再点“收起答案”即可隐藏。解答按《第二代竞赛笔记合集 有封面版.pdf》与当前小节的方法整理，注明笔记 PDF 页码（从封面算第 1 页）。同一题在不同方法小节下分别提供对应解法；笔记中有多种方法时可一并保留。整理文字与补足的推导不是原作者逐字答案；讲义题面与笔记有差异时，解析中分别说明，不混用条件。需要离线练习时，可下载包含全部题图与解答的离线版；打印题组时隐藏答案。

本页不自动判分；看答案不会改变练习状态，“已完成”仅为你自行记录。需要讲解或批改时，可把题号和过程发到聊天里。

记录保存在当前浏览器中，建议定期导出 JSON 备份。换浏览器、改文件路径、清理浏览器数据可能导致原记录不可见；导入时按题合并，优先保留更新时间更晚的记录。

这本练习册怎么用

  1. 左侧按讲义顺序选章，搜索当前范围内的知识点；也可以选“全部知识点”跨章搜索。
  2. 每个知识点练 1～2 题，题图可左右滑动，点击可放大；标注页码为讲义页脚页码，另列 PDF 页码。
  3. 先独立做题，点击“看答案”对照本节方法及笔记页码；答案可收起或点击放大，查看答案不会改变练习状态。
  4. 做完标记“已完成”；卡住或出错就标记“需复习”，在笔记里记下卡在哪一步。
  5. “随机练一题”从当前筛选范围抽取一道；“打印当前题组”打印整个筛选范围。
  6. 进度自动保存在当前浏览器。用“导出记录”备份，换设备或浏览器后可导入。

选题以讲义中的完整题目和方法对应为准，不把初赛、决赛题统称为基础题。全册没有人为增加的进度目标，按你自己的节奏练习。
