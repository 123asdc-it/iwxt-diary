# 计算机知识图谱：学习路线

公开入口 `/apps/cs-atlas/?layout=route&topic=overview`，无需登录。

- `learning-routes.json`：27 个方向的模块路线、前置深度、过渡知识、内部顺序与验收任务。
- `module-registry.json`：原知识树 352 个直接模块的稳定 ID、方向、阶段、名称。叶子知识通过所属模块关联路线，不把每个叶子称为独立验证的课程单元。
- `learning.js`：路线视图与先修回溯。任选分支不自动全部列入必修。
- `app.js`、`styles.css`、`index.html`：维护源文件；保留原紧凑树和分栏阅读。
- `source-audit.json`：审查时使用的大学课程与官方资料及支持范围。

运行 `node scripts/atlas/validate.mjs` 检查全部模块覆盖、精确名称映射、引用有效性、必需字段和依赖无环；所有任选分支也参与保守无环检查。循环引用必须修正，不能静默忽略。

`npm run build` 会先验证路线，再生成带内容哈希的公开资源，最后构建博客。新版本保留原公开资源，避免缓存中的旧 HTML 引用失效。中间开发版本无需提交。

四级掌握标准：认识（识别用途）、理解（解释并手推例子）、会用（独立完成并排错）、能实现（实现简化版本并验证边界）。这不是完成记录；用户仍应做任务检验。模块编号只是建议顺序，严格前置以 requires 为准。

资料支持主题与课程前提，模块顺序、过渡、自检是本项目重新组织的教学设计；不得描述成官方认证或保证知识零缺漏。

## 图谱内学习导航

默认打开 `layout=tree`。模块节点显示阶段内编号、选修性质与先修项数；点击节点即显示学习导航。更深知识点明确继承所属模块要求。橙色节点与虚线箭头表示当前模块的先修（只对已展开的模块绘制），蓝灰节点表示直接后续应用。

`inspector.js` 在侧栏内递进查看前置、任选入口、模块内顺序、过渡和验收；点击先修不会导航页面或移动原图。显式“在图中定位此模块”可跨方向定位，`app.js` 保存视角、选中节点和展开状态，支持“回到原图”。手机使用下半屏面板，图谱与面板分别滚动。`node` 查询参数保存具体选中知识点，`path` 继续保存图谱聚焦范围。
